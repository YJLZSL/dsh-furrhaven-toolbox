## 三、长期更新计划（v1.0 之后）

### 3.1 平台跟踪与口径重测（常态机制，季度节奏）

- **平台观察**：FD/FC/FB/ST/RisuAI/类脑 的字段、限额、组件协议、上传流程变更跟踪；DSH 上游（dev preview，官方预告破坏性变更）每次升级先跑 preset 自测。
- **口径重测**：任一平台疑似改版 → `fh calibrate <平台>` 探针实测 → platforms.yaml 修订（附证据）→ 全项目 `fh check` 重算 → CHANGELOG 记录。**口径三次改版返工潮的历史不再重演。**
- 兼容政策：口径表带版本号；旧项目构建时按锁定的口径版本出产物，升级显式触发。

### 3.2 素材生态：模板与包市场（v1.1 - v1.3）

统一「包」格式（目录 + manifest），四类可分享可安装：

| 包类型 | 内容 | 安装 |
|--------|------|------|
| 组件集包 | 四件套 + 槽位协议 + 主题表（如：幻景引擎 vn4 / 仿终端风 / 手账风） | `fh comp install` |
| 正则包 | 规则库 + 测试用例（如：统一渲染 v2.3 / 轻量版 / 极简纯文本） | `fh regex install` |
| 规则包 | lint 规则+参数（题材包：furry/古风/科幻…） | fh.config 引用 |
| 卡型模板 | custom 卡型全声明（如：团队卡/多主角/解谜逃脱/经营养成） | `fh types install` |

社区分享渠道：git 仓库即包（对齐 DSH 生态的 dsh-plugin topic 模式）；官方索引仓库收录。

### 3.3 卡型生态扩展（v1.x 持续）

按需求热度排队的候选卡型（每卡型 = M8/M9 同量级的专项里程碑）：
- **团队卡**：多角色常驻队伍（npcRoster 变体 + 队友好感矩阵组件）；
- **多主角/双视角卡**：视角切换协议 + 双状态面板；
- **解谜/逃脱卡**：道具/线索/锁解系统条目 + inventory 组件；
- **经营养成卡**：资源/日程/成长曲线规则包 + ledger 组件。

### 3.4 AI 辅助创作深化（v1.x - v2）

- **多模型流水线**：模板分工表升级为声明式流水线（flash 初稿 → max 重写 → flash 审计循环），经 DSH workflow/subagent 编排；
- **生成-评审-修复闭环**：lint 规则 ID × 自动修复建议语料 → AI 定点修复工作流（spec 模式整体重写纪律内化）；
- **创作智能体预设进阶**：card-forge persona 按实测持续调优（对齐 routing-suite 的 P 编号实验文化：每个 persona 改动带实测记录）。

### 3.5 版本与兼容政策

- semver：1.x 期间口径/IR schema 破坏性变更 bump minor + 迁移命令（`fh migrate`）；
- IR schema 带版本号，旧项目自动提示迁移路径；
- preset/plugin 版本 = 引擎版本（`fh --version` 单一来源）；
- 每里程碑收尾：pytest 绿 + selftest + 灰野/莱昂穿越/僵尸百分百/大世界样例 四标杆回归。

### 3.6 维护节奏约定
