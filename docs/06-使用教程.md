# Furrhaven 使用教程（v1.3.0）

> 版本：1.3 | 2026-08-16 | 权威级别：教程 | 适用：fh 1.3.0 / DSH 附属插件 @dsh-external/dsh-fh-tools 1.3.0

## 1. 安装

```powershell
pip install -e .\furrhaven-core
fh --version                  # fh 1.0.0 (furrhaven-core)
fh check --selftest           # 引擎自检（10+ 项全绿才能交付）
```

DSH 三件套：

```powershell
.\install.ps1                 # 引擎 + card-forge preset + selftest
# 插件：dsh/plugin/fh-tools 已编译；用 super-injector：
#   dev_inject_plugin <repo>\dsh\plugin\fh-tools
# 技能：dsh/skill/furrhaven-card → ~/.dsh/skills/furrhaven-card
```

## 2. 两种写卡模式

| 模式 | 命令 | 适合 |
|------|------|------|
| 模块化 IR | `fh new <slug>` | 多人协作、diff 友好 |
| 完整卡单文件 | `fh new <slug> --full` | 一把梭作者：卡体+世界书+组件+正则都在 `card.md` |

解析器兼容 `# name/# personality`、front-matter、中英文标题、fenced YAML/JSON；外部卡用 `fh import <FD JSON|ST PNG/JSON|任意 md>`。

## 3. 三工坊

```powershell
fh wb sim --card X --text "样例玩家消息"   # 世界书触发模拟（含递归 depth=1）
fh wb keys                                # 单字/泛词/跨卡冲突分析
fh comp new vnHeader ; fh comp check      # 组件脚手架 + FD 五坑/拉长四禁
fh regex test --text ">你好，*动作*"        # FC v2.3 渲染测试台
fh showcase                               # 动画总览（字节条/槽位协议/触发演示）
```

## 4. 门禁 / 构建 / 审阅

```powershell
fh check                    # 退出码 0 = 可交付；漂移/字节/组件/正则全查
fh budget --card X          # 字段级字节余量
fh build --platform all     # FD / FC / FB / 酒馆 V2+V3 PNG / Risu / 类脑
fh review export --card X   # 审阅稿 + EDITING 锁（期间 build 被拒）
# 外部 AI 改审阅稿后：
fh review apply --card X    # 回写 IR + 门禁通过才解锁；失败可 abort
```

## 5. 识图与扮演

```powershell
fh vision .\assets\立绘.png --card X        # 外貌描述写入 assets/
fh vision 截图.png --mode ui                # 平台组件截图排查
fh play X --say "你好"                       # 单轮扮演测试
fh play X                                   # 交互式试玩
```

模型接口配置在 `fh.config.yaml` 的 `play` / `vision` 段，或用 `FH_LLM_API_BASE/KEY/MODEL`。

## 6. DSH 生态（插件）

- 主仓 `dsh-furrhaven-toolbox`；插件包名 `@dsh-external/dsh-fh-tools`（bundle，`dsh plugin add` 可装）。
- 安装后自动注册 9 个 `fh_*` 工具 + `furrhaven-card` 技能；卸载即删。
- GitHub topics：`dsh-plugin` / `deepseek-harness`。

## 7. 平台口径速查（2026-08-16 修订）

- FD：卡 50,000 / 世界书独立 30,000 / **单组件 source ≤20,000**（UTF-8 字节）。
- FC：**上传资料包总限 40,000**（卡+开场白+简介+世界书+回复格式+正则+故事线）。
- FB：单卡 10,666。
- 酒馆/Risu：V2 `chara` chunk + V3 `ccv3` chunk；`dist/st/*.world.json`、`*.regex.json` 可单独导入。
