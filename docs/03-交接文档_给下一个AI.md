## 一、这是什么

Furrhaven 是 DSH 附属插件 `@dsh-external/dsh-fh-tools`，安装后自动提供：

- 9 个 `fh_*` 工具：`fh_new / fh_build / fh_check / fh_audit / fh_wb_sim / fh_comp_check / fh_regex_test / fh_vision / fh_play`
- `furrhaven-card` 技能（写卡流程纪律 + 官方 `changeMsg`/`getMsgContent` 思路 + 防 AI 味提示包）
- bundle 层（`cordis.patch.yml`），支持 `dsh plugin add` 官方安装

底层引擎是独立 Python 包 `furrhaven-core`（CLI `fh`），插件是薄封装。

## 四、开发与验收

```powershell
python -m pytest furrhaven-core\tests -q
fh check --selftest
node --test dsh/preset/card-forge/test/
```

插件改动后：

1. `dsh/plugin/fh-tools` 下 `npx tsc -p tsconfig.json`
2. `dev_uninject_plugin dsh-fh-tools` → `dev_inject_plugin <插件目录>` → `dev_plugin_status` 确认 active
3. `npm pack` 产出 tgz，作为 Release 附件

## 五、铁律

1. 平台 JSON 只许 `fh` 脚本读写。
2. 批量修改前先 git commit。
3. 门禁退出码 0 才可交付。
4. 插件必须“即安即用、即删”：所有注册走 `ctx.effect`，卸载自动清理。
5. 题材中立：furry 规则只在 `genre-furry` 包。
