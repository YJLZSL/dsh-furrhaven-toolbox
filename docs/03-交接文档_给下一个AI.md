## 一、你要做什么（一句话版）

按 `docs\01-架构框架设计.md`（v2.0）落地 **Furrhaven Toolbox**：**全类型角色卡创作工具箱**（兽人出身、不限题材），五大能力面 = 卡体写作 + 世界书工坊 + 组件工坊 + 正则工坊 + 多平台导出（FD/FC/FB/V2V3）；Python 核心引擎（`fh` CLI）+ DeepSeek-Harness 前端三件套（preset `card-forge` / skill `furrhaven-card` / plugin `fh-tools`），兼容 dsh-routing-suite（风神）路由。从 M0 开始按 `docs\02-开发更新计划.md` 推进，验收全绿才进下一期。

**v2.0 方向修正要点（用户 2026-08-16 拍板，不得回退）**：
1. 参考项目只是**思路来源**，不是必须遵循的模板——不照搬其兽人专属假设；
2. 支持**非兽人**角色卡：题材规则进可选规则包（genre-furry 是 opt-in），全链路题材无关；
3. **模拟器卡、大世界卡**等特殊卡型是一等公民（M8/M9）；
4. **组件、正则、世界书三工坊**是产品核心（M3-M5），不是附属导出功能；
5. 计划已细化 + 长期更新路线（v1.x→v2）已立。

## 五、开发纪律（继承，违反=返工）

1. **平台 JSON 只许脚本读写**（json.load → 改 dict → json.dump(ensure_ascii=False) → 复验）。
2. **批量前先 commit**；**改一张卡先平台实测再批量**。
3. **门禁文化**：`fh check` 退出码为准，先修复再汇报。
4. **参考项目只读**：要改它的冲动 → 停下问用户。
5. preset 插件**零外部 import**；service 行 isolate realm；不注册 `dev_router_*` 冲突名。
6. 文档变更双向登记（README 导航 + 本交接文档），页首四件套（版本/日期/权威级别/上游来源）。
7. 平台结论必须实测留证，不接受"应该是"。
8. **题材中立**：引擎与默认模板不得硬编码任何题材假设；furry 规则只存在于 genre-furry 包。

## 六、平台知识速查（浓缩版；细节查全流程文档/调研报告）

- **字节口径 v3.0（FD）**：计 personality+scenario+world_view+mes_example+response_format+组件 ai_prompt 的 **UTF-8 字节**（中文 1 字=3 字节）≤50,000；first_mes/quick_replies/正则/组件源码/world_info/标题简介**不计**；世界书独立 30,000；单组件 source ≤20,000（JSON 转义后）。
- **FD 组件五坑**：`$变量$` 只在 html 替换；id 必须字符串=name；html 禁 style/script/meta；残留组件条目整卡失败；占位符 ↔ 消息标签参数名逐字一致。
- **拉长四禁**：infinite 真实动画 / min-height / fixed 全屏层 / setInterval 逐秒改 DOM；安全 = 伪元素动画 + postMessage 三次报高（150/500/1200ms）。
- **正则陷阱（FC）**：全匹配 wrapper 放最后（否则 `^`/`$` 锚到 HTML 边界）；单双星号互斥用 `(?<!\*)\*(?!\*)`。
- **上传通用**：先删旧卡再导入；核对文件大小/时间戳；历史消息不重渲染组件；FC 两个保存按钮 + 先删后填五步法。
- **好感铁令 12/13 / 性格内核铁律**：character 恋爱向默认预填（原文：参考项目 `05-交接与报告\17卡好感节奏与全卡AI味清洗交接任务书.md` §二，一字不削弱；非恋爱卡可关）。
