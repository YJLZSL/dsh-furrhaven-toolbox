# Furrhaven Studio · 桌面端与移动端方案

> 版本：1.0 | 2026-08-16 | 权威级别：规范（前端） | 上游来源：用户方向「正式桌面端 + 尝试安卓端 + 打磨前端/动画/美术风格」

## 一、技术选型

| 层 | 选择 | 理由 |
|----|------|------|
| 桌面壳 | **Tauri 2**（Rust + 系统 WebView2） | 安装包 ~2MB、内存占用低；同一套前端可走 Tauri mobile 出 Android |
| 前端 | **原生 TypeScript + Vite**（无框架） | 工具型 GUI 不需要 SPA 框架；动画/主题全部手写 CSS，可控可打磨 |
| 后端命令 | Rust `invoke` → `fh` CLI（无 `fh` 时回退 `python -m furrhaven.cli`） | 引擎与宿主分离原则；GUI 不重新实现业务逻辑 |
| Android | Tauri 2 mobile（Kotlin 壳 + 同前端 dist） | 已生成 Gradle 工程；触控布局与文件选择是主要适配点 |

## 二、美术风格：「金箔暖纸工坊」

- **色板**（与 FC 正则 v2.3 暖金纸页体系同源）：
  - 底：深褐木案 `#14100c → #1d1610`
  - 纸：米纸 `#f5eee0 / #fdfaf3`
  - 金：暖金 `#b8860b`、亮金 `#e8c87e`
  - 墨：深褐 `#2b2118`、暖褐 `#8b7355`
- **材质**：纸张噪点 grain（SVG feTurbulence，7% 叠印）、顶部金线、火漆印章、衬线字体栈（Noto Serif SC / Source Han Serif SC / STSong）。
- **品牌图形**：48px 兽爪印 + 双环印章 SVG，桌面图标（1024px 生成）同步用于 Android mipmap。

## 三、动画规范（全部尊重 prefers-reduced-motion）

| 动画 | 实现 | 时长/曲线 |
|------|------|-----------|
| 面板切换 | `panel-rise`（上浮 + 淡入） | 460ms `cubic-bezier(.2,1,.3,1)` |
| 字节余量条 | 宽度过渡 + 金色 shimmer 扫光 | 900ms / 2.8s loop |
| 卡牌 hover | 上浮 4px + 阴影加深 | 300ms |
| 背景浮尘 | 8 颗金色微尘漂移（错峰 delay） | 14s linear |
| 构建中 | 金环 spinner | 0.8s linear |
| 印章呼吸 | 品牌 emblem 微缩放 | 5s ease-in-out |
| 脏文件点 | 红色圆点脉冲 | 1.2s |
| 按钮 | hover 上浮 1px + 金辉 | 220ms |

安全规则：禁用无限真实元素动画进组件面板（FD 拉长四禁）；GUI 自身动画只用 transform/opacity，不触发布局。

## 四、界面结构

```
顶栏    项目开关（目录选择器）+ 引擎版本徽章
侧栏    工作台 / 卡编辑 / 三工坊 / 构建发布 / 扮演试玩 / 识图 / 设置
工作台  卡列表（每平台字节条）+ 全项目审计
编辑器  文件树（cards/<slug>/ 递归 md/yaml）+ 正文编辑器 + 脏标记
三工坊  wb sim / comp check / regex test
构建    FD FC FB ST Risu 类脑 多选 → dist/
底栏    状态 + 口径速查（FD 组件20k · FC 总限40k · FB 10666）
```

## 五、Android 可行性结论（2026-08-16 实测到当前步骤）

| 步骤 | 结果 |
|------|------|
| `tauri android init` | ✅ 成功（本地 SDK/NDK 23.1 + JDK 21 + 4 个 rust android targets） |
| Rust android 库（arm64-v8a .so） | ✅ 编译成功并链入 jniLibs |
| Gradle 8.14.3 + AGP 依赖解析 | 🔶 首次尝试被系统代理证书拦截（Java PKIX）；改用 Windows-ROOT truststore 后继续 |
| APK 出包 | 🔶 进行中（assembleDebug） |

结论：**技术上可行**，同一前端/后端命令面可复用；剩下的是 Gradle 网络证书适配、触控布局（侧栏折叠、移动端字号）、Android 上的 `fh` 引擎打包策略（方案：APK 内随包携带 Python 引擎，或改为 Rust 端内嵌轻量 IR 操作——推荐后者作为正式移动端路线）。

## 六、构建产物

- 桌面免安装：`app/src-tauri/target/release/furrhaven-studio.exe`
- 桌面安装包：`app/src-tauri/target/release/bundle/nsis/Furrhaven Studio_0.1.0_x64-setup.exe`
- Android 工程：`app/src-tauri/gen/android/`（debug APK 出包后见 `app/build/outputs/apk/`）
