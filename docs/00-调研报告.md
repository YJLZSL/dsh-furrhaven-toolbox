> 版本：v1.1 | 2026-08-16 | 权威级别：**调研快照（事实基线）** | 用途：为工具箱的架构设计与开发计划提供事实依据；后续事实更新以平台实测与 DSH 上游变更为准。
> v1.1 注：用户方向修正（2026-08-16）——参考项目定位为**思路来源而非模板**；工具箱支持全类型角色卡（非兽人）、特殊卡型（模拟器/大世界）、组件/正则/世界书三工坊。本报告的**事实部分不受影响**（它记录参考项目是什么），仅 §五需求画像与 §一结论的泛化方向以架构文档 v2.0 为准。

## 一、结论先行（TL;DR）

1. **参考项目已把"多平台兽人写卡"跑通了全流程**：蔚蓝市系列 17 张兽人角色卡 + 1 张模拟器卡，同时维护 FD / FC / FB 三个平台，沉淀了十段流水线、权威源分级制度、118 个 Python 工具脚本和一整套平台硬知识。**工具箱的思路 = 把这套经过实战验证的体系，泛化为全类型角色卡（不限题材）、多卡型（角色/模拟器/大世界）、三工坊（世界书/组件/正则）的通用工具链**——参考项目是思路来源与迁移资产，不是必须照搬的模板。
2. **DSH 生态已就绪**：DeepSeek Harness（Everything is a Plugin / Cordis 架构）支持 agent preset、plugin、skill 三种扩展面；本机已装 `router-standard` preset（dsh-routing-suite 组件）并在 `~/.dsh` 留有 super-injector 运行痕迹。工具箱可以做成 **DSH 原生工具（preset + skill + plugin）+ 独立 Python 核心引擎** 的双层结构。
3. **「风神插件」考证结论（待用户确认的假设）**：公开渠道（GitHub / dshplugin.store）没有名为"风神"的独立插件；社区（B 站教程圈）所说的"风神插件"与 dsh-routing-suite 的**多模型/多模式路由玩法**高度吻合（"v4flash+max 实战、一半一轮一半二轮"）。因此本工具箱按"**兼容 dsh-routing-suite（router-standard + super-injector），并支持多模型路由分工**"来设计，不硬绑定任何单一插件实现。
4. 参考项目的三大痛点正是工具箱的需求画像：**工具与路径硬编码耦合、流程纪律靠文档靠人肉、平台知识散落在交接文档里**（详见 §五）。

### 2.4 权威源制度（工具箱要直接继承的设计）

- **FD = FC = FB 同一批角色**：差别只在字节预算（FB ≤10,666 / FC ≤15,000 / FD 卡 ≤50,000），深化 ≠ 改设定。
- **单一事实源操作链**：改内核 → 先改母卡 + 角色总表 → 再更新 FD JSON → 最后重新生成审阅稿。
- **派生视图禁止当编辑源**：审阅稿 .md 由 JSON 单向生成；正确顺序 = 改 .md → `apply_review_to_json.py` 回写 → 门禁 → 再 export（顺序颠倒会覆盖未回写改动，已发生两次事故）。
- 文档页首统一标注 `版本 / 最后更新 / 权威级别 / 上游来源`。

### 2.6 FD 组件系统硬知识（最有价值的平台 know-how，工具箱必须内置为检查器）

1. **参数替换正则** `/\$(?!\{)([^$\n]{1,64})\$/g`：平台**只替换 html 字段里的 `$变量$`**，script 里永远拿不到 → 正确模式 = html 放占位符/`.sh-data` 隐藏 span，script 从 DOM 读 + `clean()` 检查残留 `$`。
2. **组件 id 必须字符串且 = name**（int 哈希 id → css/script 全不生效，只渲染扁平 html）。
3. **html 清洗器**剥离 `script/iframe/object/embed/link/meta/style` → html 只能放纯结构。
4. **渲染模式判定**：script 含 `const|function|document.|setInterval(` 等 → iframe 模式；改完必跑 `node --check`。
5. **桥接函数白名单**（28 个）：`fillInput` 是选项交互唯一标准方式；`saveToLocal/readFromLocal/getWorldInfo` 在 iframe 模式是 Promise。
6. **高度拉长防线**：禁 infinite 真实元素动画 / min-height / fixed 全屏层 / setInterval 逐秒改 DOM；安全做法 = 伪元素动画 + `postMessage` 主动报高（150/500/1200ms 三次）。
7. **参数名对齐**：html 的 `$xxx$` 与消息标签 `<xxx>` 必须逐字一致（错一个就显示空）。
8. **平台导入检查所有组件条目**（含未使用）→ 残留组件会导致整卡导入失败，更新器必须清理。
9. 17 卡组件 = vnHeader/vnMap/vnThought/vnFooter 四件套（幻景引擎 v3，9 种天气参数化）；模拟器卡 = HUD/vnMap/Choices 三件套（phase 四态）——**两套组件体系并存**，组件库引擎必须支持多组件集。

### 2.7 质量体系（工具箱 lint 规则的直接来源）

- **145 分制 12 维度评审**，一致性铁律一票否决。
- **好感节奏铁令 12/13**（response_format 第 12/13 条）：`<level>` 涨幅分档 + 冷却轮 + 禁跳涨；`<stage>` 1-5 逐级门控（stage1 禁暧昧 … stage5 才日常亲密），stage1-3 禁"爱/喜欢"。
- **性格内核铁律**：personality 头部【性格内核铁律】块指向 ## 7 唯一基准，禁漂移成通用温柔男友。
- **活人感文风**（human-writing 技能 + `check_prose.py`）：破折号限额、死物比喻禁用清单、"不是A是B"每字段 ≤2、抽象心理词换动作、跨卡专属词雷区表（"恰好"=灰野、"尾巴缠手腕"=曜辰）。
- **玩家性别红线**：玩家男性、指代用"他"，女性 NPC 豁免（`_fem_scan.py` 扫描口径）。
- **整体重写优先纪律**：设定改版禁逐段 patch，先通读整分区再整块替换 + `verify_all_fixes.py` 历史残留词验证。

## 三、DSH 生态调研

### 3.1 DeepSeek Harness（官方）

- 开源项目 `deepseek-ai/deepseek-harness`，命令 `dsh`，**developer preview（0.1.0-rc.x）**，官方预告未来有破坏性变更。
- 核心理念 **"Everything is a Plugin"**（基于 Cordis 组合框架）：模型适配器、工具、技能、会话、沙箱全部可插拔。
- 社区插件发现：GitHub `dsh-plugin` topic + `dshplugin.store` 插件商店 + `dsh-suite`（每小时刷新的活目录）+ `create-dsh-plugin` 脚手架。
- 扩展面三种：**agent preset**（`~/.dsh/.agent-presets\`，YAML 组合 + .mjs 插件）、**plugin**（`dsh plugin --profile web add <repo>`，提供工具/技能）、**skill**（`SKILL.md` 文件系统发现）。
- 本机 `settings.yaml`：默认模型 `deepseek-v4-pro`（reasoningEffort=max），默认 preset = `router-standard`，vision 回退 xiaomi mimo-v2.5。

### 3.2 dsh-routing-suite（yjh051108）

套件 = 两个独立演进的组件，本地均已安装/留痕：

**① dsh-router-standard（v0.1.1，已装于 `~/.dsh/.agent-presets\router-standard\`）**
- 任务感知思维模式路由 preset：读取会话首条用户消息 → 分类任务 → 首个请求注入对应 persona + 首轮核心工具面 → 首次持久 `tool/call` 后开放完整工具目录并不再干预。
- **三个实测稳定行为带**（21 点 × n=2 实测，v4-pro）：spec [0,0.15]（计划优先）/ 不稳定过渡带 [0.2,0.45]（避开）/ react [0.5,1]（动手优先）；另有 **weak 带模型自路由**（persona 按 flash/pro 分型）。
- v0.2.0 `routerMode=standard`：RL 接口还原——首轮只有 RL 训练句 persona + `shell/str_replace_editor`（实测 25 步 / 24 工具调用的迭代工作流）。
- 自调工具：`dev_router_status` / `dev_router_mode`（band 名、0-100、0.0-1.0、auto）/ `dev_mode_subagent`（用**另一模式**跑隔离子任务，不动本会话轨迹）。
- resume/reload 安全（模式从持久会话事件推导）；near-field 引导消息按任务复杂度自适应（SIMPLE/COMPLEX 两档）。
- 关键工程约束（agent.cordis.yml 注释沉淀）：service 行必须放 `isolate` realm；host-plane 注册表（shell/技能/目标/压缩/子代理注册表）preset 不得私有；`provide()` 同 realm 二次注册会抛错。

**② dsh-super-injector（v0.3.3，本机 `~/.dsh\super-injector\` 有 self-heal 日志）**
- 运行时注入器：`dev_inject`（不重启注入插件/preset）、`dev_stage_*`（侧挂晋升工具家族）、路由自愈（`purge-stale-tools`，日志可见 dev_stage_* 清理）。
- 安装链：`git clone --recurse-submodules` → `install.ps1` 或手动 `dsh plugin --profile web add .\injector` → preset 复制到 `.agent-presets\router-standard` → 重启 DSH。

## 四、通用角色卡格式格局（第二优先级方向）

> 置信度说明：本节基于社区公开常识与规范文档的一般认知整理，**具体字段以开发时抓取官方规范原文为准**（交接文档已列为 v0.6 任务，需实测验证）。

| 规范/平台 | 形态 | 关键特征 |
|-----------|------|---------|
| V1 | PNG tEXt chunk `chara` (base64 JSON) | name/description/personality/scenario/first_mes/mes_example 六字段，最老兼容层 |
| V2（spec-v2, malfoyslastname） | PNG `ccv3` chunk + JSON | V1 全字段 + character_book（lorebook 结构化）+ extensions 扩展位 + 头像字段 |
| V3（RisuAI 发起） | JSON + PNG | V2 全量 + assets 多资源 + multi 多语言副本 + 正则/快捷回复纳入规范，向前兼容 V2 读取器 |
| SillyTavern | V2/V3 PNG + 独立 world info JSON / preset JSON / regex JSON | 全球事实标准之一，类脑等中文平台普遍兼容其导入 |
| 类脑等中文平台 | 多兼容 V2/V3 导入 + 自有 JSON | 与 FD/FC/FB 同属"中文兽圈平台"，字段映射成本低于格式重写 |

**对工具箱的意义**：IR（中间表示）设计得覆盖 V3 字段全集，则 FD/FC/FB 导出器之外可以低成本增加 V2/V3 PNG 导出器，实现"一次写作、全平台分发"。参考项目已证明跨平台同设定可行，缺的只是通用格式这一层。
